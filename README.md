## ✨ Overview

**StreX** is a next-generation IPTV streaming platform designed with a sleek cyber-inspired desktop UI and optimized real-time streaming experience.

Built for both desktop and mobile devices, StreX focuses on:

* ⚡ Fast IPTV playlist loading
* 🎬 Smooth HLS streaming playback
* 🧠 Clean and intelligent navigation
* 🌌 Modern neon-glass aesthetic
* 📱 Responsive OS-style interface
* 🔍 Real-time channel search
* 📂 Dynamic IPTV category browsing
* 🔗 Custom M3U/M3U8 playlist support

The project blends a futuristic operating-system-inspired layout with lightweight performance and modern frontend architecture.



## 🖥️ Features

### 🎥 Streaming Engine

* HLS.js powered playback
* Native browser HLS fallback
* Real-time live status system
* Stream health indicators
* Modal-based immersive player

### 🧩 IPTV System

* Dynamic M3U parser
* IPTV category explorer
* Searchable channel grid
* Custom playlist loader
* Active channel tracking

### 🎨 UI / UX

* Glassmorphism design
* Cyber neon theme
* Desktop + mobile adaptive layout
* Floating liquid navigation
* Smooth animations & transitions
* Responsive OS-inspired structure

### ⚙️ Technical

* Pure HTML, CSS, and JavaScript
* No heavy frameworks
* Lightweight architecture
* Mobile-first optimization
* Fast deployment support
